On-chain prices from Jupiter Price API. Reference from Pyth Network (on-chain push oracle accounts via public Solana RPC). Mint addresses verified via xStocks / Backed public API.

xStocks quote, multiplier, trading-halt status and proof of reserves come from the xStocks (Backed) public API (no key). That API does not allow browser (CORS) requests, so a GitHub Action writes data/xstocks.json every ~30 minutes; the fetch time of each value is shown. Quote vs Jupiter / Pyth: MATCH within 1%, else DIFF. Multiplier: Jupiter prices are per scaled (UI) token = 1 share, so the premium compares them with the share price directly; equivalently, raw-token price = Jupiter × multiplier vs fair value per raw token = underlying × multiplier. HALTED (issuer isTradingHalted) suppresses premium flags.

Flags: |premium| > 100 bps, or reference older than 300s while market open = STALE. After hours gaps are labeled, not alarmed.

Token price, mark price, valuations and supply: PreStocks public API (prestocks.com/api/prestocks). Mark price is shown as published by the PreStocks API. Cross-checks: Jupiter Price API v3 (MATCH if within 1%) and public Solana RPC (getTokenSupply, getAccountInfo).

The PreStocks API does not allow browser (CORS) requests, so a GitHub Action fetches it every ~30 minutes and writes data/prestocks.json; this page reads that file and shows its age.

Flags: premium ≥ +10% = RICH vs mark; ≤ −10% = CHEAP vs mark. Not investment advice. Mark is not fair value; a premium is not an arbitrage — tokens may not be redeemable at mark.
